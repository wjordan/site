Projects

syzy

Local-first, multi-writer replication for SQLite and Postgres. Durable object-storage backing, scale-to-zero recovery, and no single writer to serialize through.

presage

A binary patcher built on the idea that most bytes which change between two builds change because something else moved. A patch is a compact plan describing what moved where, from which the decoder rebuilds a full prediction of the new file, plus a correction listing every byte the prediction got wrong. Format knowledge lives in codecs; anything no codec claims falls back to an ordinary delta.

Write-up: Slicing Chrome’s Zucchini Patches in Half.

gossip-mesh

Efficient, reliable, low-latency message broadcast across clusters of 1 to 1000+ nodes, built on QUIC. Related: memberlist-quic, a QUIC transport for hashicorp/memberlist, and vivaldi, a standalone Go module for Vivaldi network coordinates.

sqlite-prefetch

Prefetches SQLite database pages from remote storage, so a query over a network-backed database stops paying a round trip per page.
